Clinic Admin

Add, edit or remove home page articles. Changes appear on the site in about 1 minute.

1. Connect (only once)

Create a GitHub access token: GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Choose Only select repositories (your clinic site), set Contents: Read and write, then copy the token.

2. New article

No photo needed: the clinic logo on a blue background will be shown on this article.
